## 🗺️ Где «живёт» ваш сайт: 3 бесплатных сервиса

Ваш сайт не на «каком-то сервере» — он состоит из трёх бесплатных сервисов,
каждый делает своё дело:

| Сервис | Что делает | Цена | Ваша роль |
|---|---|---|---|
| **GitHub** | Хранит файлы сайта (как флешка в облаке) | Бесплатно | Создать аккаунт 1 раз, потом не заходить |
| **Netlify** | Берёт файлы из GitHub и делает из них живой сайт | Бесплатно | Создать аккаунт 1 раз, потом не заходить |
| **Decap CMS** | Админка для добавления мероприятий, материалов | Бесплатно | Заходить для правок (5–10 минут) |
| **Яндекс.Формы** (бонус) | Принимает заявки с формы «Записаться» | Бесплатно | Создать 1 форму, проверять email |

```
┌─────────────┐     ┌─────────────┐     ┌──────────────┐
│   GitHub     │ ──▶ │   Netlify   │ ──▶ │   Сайт в     │
│ (файлы)      │     │ (строит)    │     │   интернете  │
└─────────────┘     └─────────────┘     └──────────────┘
       ▲                                        │
       │              ┌─────────────┐           │
       └──────────────│  Decap CMS  │◀──────────┘
       (сохраняет     │  (админка)   │   (вы заходите
        изменения)    └─────────────┘    на /admin)
```

**Главная идея:** вы меняете контент в админке → Decap CMS сохраняет изменения
на GitHub → Netlify автоматически перестраивает сайт → изменения видны через 30 секунд.

## 🚀 Разовая настройка (выполняется ОДИН раз)

Эту часть проще сделать с помощью знакомого программиста —
займёт 2–3 часа. После этого вы справитесь сами.

### Шаг 1. Создать аккаунт на GitHub

1. Зайдите на **github.com**
2. Нажмите кнопку **«Sign up»** в правом верхнем углу
3. Введите ваш email, придумайте пароль и логин (например, `dance-club-owner`)
4. Подтвердите email по письму от GitHub
5. Готово — у вас есть «флешка в облаке»

### Шаг 2. Загрузить файлы сайта на GitHub

1. На GitHub нажмите **«+»** в правом верхнем углу → **«New repository»**
2. Назовите репозиторий `dance-club`
3. Выберите **«Public»** (важно — бесплатно для Netlify)
4. Нажмите **«Create repository»**
5. Загрузите все файлы из папки `dance-club` (которую вы скачали) —
   на GitHub есть кнопка **«Upload files»**, можно перетащить файлы мышкой.
   **Важно:** загружайте файлы, сохраняя структуру папок (папку `src`,
   `public` и т.д.).

> 💡 Если загрузка файлов покажется сложной, попросите программиста сделать
> это за 30 минут через программу `git`. Это разовая работа.

### Шаг 3. Подключить Netlify (здесь сайт «оживёт»)

1. Зайдите на **netlify.com**
2. Нажмите **«Sign up»** → выберите **«Sign up with GitHub»**
3. Разрешите Netlify доступ к вашему GitHub
4. В личном кабинете Netlify нажмите **«Add new site»** → **«Import from Git»**
5. Выберите ваш репозиторий `dance-club`
6. Настройки сборки подставятся автоматически (Netlify увидит файл
   `netlify.toml` и всё настроит сам)
7. Нажмите **«Deploy site»**
8. **Через 1–2 минуты** сайт будет доступен по адресу
   вида `https://dance-club-123abc.netlify.app`

🎉 Поздравляем! Сайт уже работает в интернете. Теперь настроим админку.

### Шаг 4. Включить Identity в Netlify (чтобы работала админка)

1. В личном кабинете Netlify откройте ваш сайт
2. Слева в меню найдите **«Identity»**
3. Нажмите **«Enable Identity»**
4. В разделе **«Registration»** выберите **«Invite only»**
   (чтобы никто посторонний не мог войти в админку)
5. В разделе **«Services»** → **«Git Gateway»** нажмите **«Enable»**
   (это позволит админке сохранять изменения на GitHub)

### Шаг 5. Создать свой логин-пароль для админки

1. В том же разделе **«Identity»** нажмите кнопку **«Invite users»**
2. Введите **свой собственный email**
3. На этот email придёт приглашение — перейдите по ссылке
4. Придумайте пароль — это ваш логин-пароль для админки

### Шаг 6. Войти в админку

1. Откройте в браузере адрес:
   `https://ваш-сайт.netlify.app/admin`
2. Введите ваш email и пароль из шага 5
3. Вы увидите 4 раздела:
   - **Мероприятия**
   - **Обучающие материалы**
   - **Тренеры**
   - **Частые вопросы (FAQ)**
4. 🎉 Готово! Теперь вы можете добавлять контент.

### Шаг 7. Создать форму в Яндекс.Формах (для заявок)

1. Зайдите на **forms.yandex.ru**
2. Нажмите **«Создать форму»**
3. Добавьте 3 поля:
   - **Имя** (тип: «Короткий ответ»)
   - **Телефон** (тип: «Короткий ответ»)
   - **Направление** (тип: «Выпадающий список», варианты: «Для начинающих»,
     «Европейская», «Латина», «Социальные», «Историко-бытовые»)
4. В настройках формы включите **«Уведомлять на email»** и впишите ваш email
5. Нажмите **«Опубликовать»** → скопируйте **ссылку на форму**
6. Откройте файл `src/components/SignupForm.astro` на GitHub
   (через веб-интерфейс: github.com → ваш репозиторий → путь к файлу)
7. Найдите строку `formAction = 'https://forms.yandex.ru/u/EXAMPLE'`
8. Замените `EXAMPLE` на ваш реальный ID формы (он есть в ссылке)
9. Сохраните файл (кнопка **«Commit changes»**)
10. Через 30 секунд форма на сайте начнёт отправлять заявки вам на email

### Шаг 8 (опционально). Купить красивый домен

Адрес `https://dance-club-123abc.netlify.app` рабочий, но длинный.
Можно купить красивый домен вроде `танцы-клуб.рф` за ~1000₽/год:

1. Зайдите на **reg.ru** или **nic.ru**
2. Найдите свободный домен, оплатите
3. В личном кабинете Netlify: **«Domain settings»** → **«Add custom domain»**
4. Netlify покажет, какие DNS-записи прописать у регистратора —
   скопируйте их в настройки домена у reg.ru
5. Через 1–2 часа сайт откроется по вашему красивому адресу

## 🧠 Универсальный алгоритм: 3 шага для любых правок

Этот алгоритм подходит для всех будущих изменений (кроме добавления
контента через админку — для этого просто заполните форму).

### Шаг 1. Сформулируйте, что хотите изменить

Например:
- «Хочу добавить новый бал на 25 декабря» (это через админку — проще)
- «Хочу поменять цвет всех главных кнопок на более светлый»
- «Хочу добавить поле Email в форму записи»
- «Хочу изменить заголовок на главной странице»

### Шаг 2. Скопируйте нужный промт из этой инструкции

Откройте раздел **«Готовые промты для нейросети»** ниже, найдите подходящий
шаблон, скопируйте его целиком (вместе со скобками).

### Шаг 3. Подставьте свои данные и отправьте нейросети

1. Вставьте промт в чат с Qwen / DeepSeek / ChatGPT
2. Замените текст в квадратных скобках `[ВОТ ТАК]` на ваши данные
3. Если промт просит «вставить код» — откройте на GitHub нужный файл,
   нажмите кнопку **«Raw»** (или просто скопируйте содержимое файла),
   вставьте в промт
4. Отправьте сообщение нейросети
5. Скопируйте ответ нейросети

### Шаг 4. Вставьте код обратно на GitHub

1. На GitHub откройте нужный файл (нейросеть скажет, в какой)
2. Нажмите кнопку **✏️ Edit** (карандашик в правом верхнем углу файла)
3. Выделите весь старый текст и удалите его
4. Вставьте новый код, который дала нейросеть
5. Нажмите **«Commit changes»** (зелёная кнопка)
6. **Через 30 секунд изменения появятся на сайте**

Это всё! Никакого программирования, только текстовые операции.

## 🍳 Частые сценарии — пошаговые рецепты

### Рецепт 1. Добавить новое мероприятие (через админку — РЕКОМЕНДУЕТСЯ)

1. Зайдите на `https://ваш-сайт.рф/admin`
2. Войдите (email + пароль)
3. Слева нажмите **«Мероприятия»**
4. В правом верхнем углу нажмите **«Добавить»** (или «+»)
5. Заполните форму:
   - **Название**: «Новогодний бал»
   - **Дата (ISO)**: выберите дату в календарике
   - **Дата (отображается)**: «25 декабря»
   - **Тип мероприятия**: выберите «Бал»
   - **Описание**: 2-4 предложения
   - **Время**: «20:00 — 23:00»

## 🆘 Что делать, если что-то сломалось

**Главное правило: не паникуйте.** Все изменения сохраняются в
истории GitHub, и всегда можно вернуться к предыдущей версии.

### Ситуация 1: Сайт стал белым / не открывается

1. Откройте на GitHub **«Actions»** (вкладка сверху репозитория)
2. Если там красный кружок — значит, в последний раз сайт не собрался
3. Нажмите на этот красный кружок → посмотрите, какой файл вызывает ошибку
4. Откройте этот файл, нажмите **«History»** (история изменений)
5. Найдите последнее изменение перед ошибкой, нажмите **«…»** → **«Revert»**
6. Через 1 минуту сайт снова заработает

### Ситуация 2: Не могу войти в админку

1. Зайдите на Netlify → ваш сайт → **«Identity»**
2. Проверьте, что ваш email есть в списке пользователей
3. Если нет — добавьте его через **«Invite users»**
4. Если забыли пароль — нажмите **«Recover password»**

### Ситуация 3: Ссылка на Яндекс.Диск не работает

Проверьте, что в настройках доступа файла на Яндекс.Диске включён
режим **«Доступ по ссылке»** (а не «Только вы»). Это самая частая
ошибка.

### Ситуация 4: Заявки с формы не приходят на email

1. Зайдите на forms.yandex.ru → вашу форму
2. В настройках проверьте, что включено **«Уведомлять на email»**
3. Проверьте папку «Спам» в почте — иногда письма попадают туда

### Ситуация 5: Что-то другое — опишите нейросети

Используйте **Промт 7** (SOS-промт) из раздела выше.
